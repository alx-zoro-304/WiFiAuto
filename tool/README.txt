WiFi Auto - حزمة التشغيل الكاملة (ويندوز)
==================================

المحتويات
---------
- wifi_auto_gui.py      : الأداة الرئيسية (WiFi Auto v2.1) — فيها تبويب MikrotikSploit مدمج
- mac_changer_pro.py    : أداة تغيير MAC مستقلة
- MikrotikSploit/       : حقيبة اختبار أمان ميكروتيك (تبيض جميع ثغراته المعروفة)
- start.bat             : تشغيل WiFi Auto (بصلاحيات المسؤول تلقائياً)
- start_changer.bat     : تشغيل MAC Changer Pro
- MAC-Address-Tool.exe  : نسخة مستقلة مجمّعة من MAC Changer Pro (بدون بايثون)
- updater.py            : نظام التحديث التلقائي (يفحص موقع المطوّر)
- report.txt            : سجل الجلسة الحالية (يبدأ فارغاً كل تشغيل)

التشغيل
-------
1. انقر نقراً مزدوجاً على start.bat لتشغيل الأداة الرئيسية.
2. عند ظهور نافذة UAC اضغط "نعم".
3. ستجد تبويبين داخل الأداة: "WiFi Auto" و "MikrotikSploit".
4. لاستخدام أداة تغيير MAC المستقلة استخدم start_changer.bat.

التبويب MikrotikSploit
----------------------
- يختبر جميع ثغرات ميكروتيك المعروفة: فحص الثغرات، اختبار لوحة الإدارة،
  اكتشاف بطاقات الدخول، ووحدة ضغط DoS.
- يعمل داخل نافذة الأداة نفسها (console مدمج) أو مستقلاً.
- متطلباته: colorama + requests + bs4 — ثبّتها مرة واحدة:
  python -m pip install -r MikrotikSploit/requirements.txt

ملاحظات
-------
- البرنامج كامل بذاته (self-contained): لا يحتاج أي برنامج خارجي أو
  سكربت إضافي. تغيير الـ MAC يتم داخل السكربت: تعطيل الكارت -> كتابة
  قيمة NetworkAddress في السجل -> إعادة التفعيل (الطريقة المجربة مع
  Realtek 8821CE). الفحص يتم بـ ping نصي بالكامل داخل بايثون.
- البرنامج لا يحفظ أي بيانات من الجلسات السابقة:
  report.txt يبدأ فارغاً في كل تشغيل.
- الفحص العميق: يمسح كل عناوين الشبكة (2044 عنواناً) طوال 15 ثانية
  كاملة في جولات متكررة ويدمج النتائج حتى يلتقط الأجهزة البطيئة.
- أي MAC يرفض التغيير (التعريف يعيده) -> يتخطاه فوراً ويجرب التالي.
- يشترط وجود Python 3 مثبتاً على الجهاز (ويفضل 3.8+).
- التحديثات تلقائية: عند صدور إصدار جديد يظهر لك تنبيه يطلب موافقتك،
  وينشئ نسخة احتياطية (.bak) قبل أي تحديث.

للإبلاغ عن مشكلة أو تعديلات: راجع سجل report.txt داخل هذا المجلد.
