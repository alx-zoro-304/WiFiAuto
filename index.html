Quick start

How to use

Both tools run in under a minute. Here's the whole guide — compact.

📡 WiFi Auto

Windows

  1. Run start.bat (UAC opens → Yes)
  2. Pick an open network → press Start
  3. Done — internet works automatically

Linux

  1. Double-click WiFi Auto.desktop (asks password)
  2. Pick an open network → press Start
  3. Done — internet works automatically

Or from terminal: ./start_wifi_auto.sh

Requires Python 3.8+. Needs admin/root for MAC change and deep scan.

🖥️ MAC Changer Pro

Windows only

  1. Run start_changer.bat (UAC opens → Yes)
  2. Select your adapter → enter a MAC
  3. Press Apply — or Restore to go back

If a driver rejects the change, the tool tells you exactly why and what to try.
